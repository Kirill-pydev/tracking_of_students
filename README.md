# Система учета учеников ЦЦОД «IT-куб»

Десктопное приложение на Python с графическим интерфейсом для автоматизации учета учащихся, управления учебными группами и контроля посещаемости в Центре цифрового образования детей «IT-куб».

Приложение построено на современной компонентной архитектуре, разделяющей интерфейс, бизнес-логику и работу с данными.

## 🛠 Технологический стек

*   **Язык программирования**: Python 3.10+
*   **Графический интерфейс (GUI)**: [PyQt6](https://pypi.org)
*   **ORM (Работа с базой данных)**: [SQLAlchemy](https://sqlalchemy.org)
*   **База данных**: SQLite (локальный файл БД)

## 📂 Структура репозитория

*   `main.py` — главная точка входа, инициализация и запуск приложения.
*   `ui_models/` — слои графического интерфейса, кастомные виджеты, формы и окна PyQt6.
*   `core/` — основная бизнес-логика приложения, валидация данных и обработка процессов.
*   `db/` — подсистема базы данных (описание моделей SQLAlchemy, сессии, создание таблиц и миграции).
*   `requirements.txt` — файл со списком внешних зависимостей проекта.

## 🚀 Основной функционал

*   **Управление базой учеников**: добавление, редактирование, удаление и поиск студентов ЦЦОД.
*   **Фильтрация и распределение**: привязка учащихся к конкретным учебным направлениям (кубам) и группам.
*   **Надежное локальное хранение**: использование ORM SQLAlchemy обеспечивает безопасную работу с базой данных SQLite без риска потери данных.
*   **Асинхронность/Стабильность**: отзывчивый интерфейс PyQt6, отделенный от тяжелой логики запросов к БД.

## 💻 Установка и запуск

### Требования
На вашем компьютере должен быть установлен **Python версии 3.10 или выше**.

### Пошаговая инструкция

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com
   cd tracking_of_students
   ```

2. **Настройте виртуальное окружение**:
   * **Windows**:
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```
   * **Linux / macOS**:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. **Установите зависимости**:
   При установке автоматически развернутся PyQt6, SQLAlchemy и сопутствующие библиотеки.
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение**:
   При первом запуске SQLAlchemy автоматически создаст необходимый файл базы данных SQLite (если это заложено в логике вашего модуля `db`).
   ```bash
   python main.py
   ```
